# Tridium
A 3D game engine featuring an Editor, Physics, ECS, C++ Runtime-Reflection, Serialization, PBR Graphics, and a dynamically-bound RHI system with support for OpenGL and DirectX12.

> [!IMPORTANT]
> This project is still in development so there will be bugs.

## Setup

```bash
git clone -b RHI --single-branch https://github.com/AsherFarag/Tridium.git
cd Tridium
git submodule init
git submodule update --init --recursive
GenerateProjects
```
This will create a Visual Studio 2022 solution you can run.
